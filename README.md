# Inmobiliaria

Proyecto inmobiliario desarrollado para administrar propiedades, captar clientes potenciales y construir una plataforma digital de ventas y rentas.

## Objetivo inicial

Construir de forma incremental:

- Catálogo público de propiedades
- Backend API
- Base de datos PostgreSQL
- Panel administrativo
- Captura de leads
- Seguimiento de clientes
- Métricas y analítica

## Stack previsto

- Frontend: Angular
- Backend: Python + FastAPI
- Database: PostgreSQL
- API: REST
- Version control: Git + GitHub

## Estado

Proyecto en etapa inicial de desarrollo.

La aplicación se está construyendo con enfoque educativo e incremental.
